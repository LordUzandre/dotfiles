This is a repository of all configs for my dotfiles.

# Install guide:
1. Download repository with `git clone https://github.com/LordUzandre/dotfiles.git`
2. Run `chmod +x install.sh` to install script.
3. Run install-script with `./install.sh`
4. The script creates symbolic links to all matching files and creates backups for previous instances.

Linux CachyOS
