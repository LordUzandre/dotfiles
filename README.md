This is a repository of all configs for my dotfiles.

# Install guide:
1. Download repository with `git clone https://github.com/LordUzandre/dotfiles.git`
2. Run install-script with `source install.sh` or `chmod +x install.sh && ./install.sh`
3. The script creates symbolic links to all matching files and creates backups for previous instances in the local directory.

# Tested on:
MacOS: TaHoe
Linux: Arch and, Ubuntu

# Currently included configs:
- vim
- aliases for:
  - bash
  - zsh (with p10k-theme)
